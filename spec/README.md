# Runbook app — spec and wireframes

Wireframes and spec for a local runbook app: write ops runbooks as ordered shell steps,
run them one at a time or all at once, keep the output, share as Markdown.

## Files

- `SPEC.md` — data model, run semantics, screen list, paste/export format, open questions.
  **Read this first.** It answers the things the wireframes can't show.
- `wireframes.html` — all screens, one self-contained file. Open in a browser. Each screen
  has a badge (`2a`, `4a`, `6b`…) that `SPEC.md` refers to.

- `PROMPT.md` — the kickoff prompt to paste into Claude Code, with build order and ground rules.

The wireframes are low-fidelity by intent — take layout and states from them, not styling.
